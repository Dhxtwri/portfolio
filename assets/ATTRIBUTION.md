# Character Artwork & Asset Notes

This directory contains the local SVG character illustrations used in Dhairya Tiwari's Invincible-inspired developer portfolio. The files are resolution-independent vectors with no external image dependencies.

These character depictions are not presented as official publisher artwork. The repository contains no third-party source or reuse-license record for the underlying character designs, so this file does not claim permission or rights clearance. Replace them with licensed or original non-character illustrations if cleared character rights are required for publication.

## Replacing an illustration

To use a transparent PNG cutout, place it in this directory and update the matching `<img class="character-art-img">` source in `index.html`. The existing layout uses `object-fit: contain` to preserve the image proportions.
